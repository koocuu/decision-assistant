# 决策助手产品文档

本文档回答“我们到底在做什么”。它是产品事实源，不写实现细节。

## 当前目标（2026-06-25 更新）

- **定位 = 作品集 + 简历 + 给朋友装逼，低成本优先**；不重押规模化用户增长。
- 重点 = UI 精美（克制高级）+ 完整闭环可演示 + 线上可分享 + 干净 README/复盘。
- 战略教训（详见 `docs/产品方向备忘.md`）：AI 能力已商品化，**稀缺的是分发/人群**；消费 AI 多为红海；下一个"生意级"产品应从"自带受众的场景"切入（如导师+学员），再复用本项目技术骨架。

## 产品定位

决策助手是一个面向个人复杂选择的 AI 决策工具。用户可以把纠结的问题随手写下来，系统帮他拆成可比较的选项、风险、权重和后续复盘。

核心风格是“小羊暖外壳 + 理性分析内核”：入口要轻，反馈要温和，结论要清楚。

## 目标用户

- 需要快速整理选择的人：吃什么、买什么、要不要换工作、要不要投入某件事。
- 希望有记录和复盘的人：以后能看到自己为什么做了这个决定。
- 对传统表格/矩阵没耐心，但愿意用聊天式输入的人。

## 核心流程

1. 用户输入一个纠结点。
2. AI 先把问题整理成决策草稿。
3. 用户确认或修改选项。
4. AI 生成报告和建议。
5. 用户后续补充结果，形成复盘和个人画像。

## 账号与匿名体验

- 匿名用户也必须能完整生成报告。
- 登录后，历史记录跟随账号跨端可见。
- 登录/注册不能成为首次体验的硬门槛。
- App 和 Web 共用同一套后端账号体系。

## 分发策略

- Web 保留为主要公开入口，承载 PC Web、移动 Web、SEO、分享和下载入口。
- Expo App 负责 Android/iOS 原生体验。
- 不继续投入 PWA 安装路线。
- 微信小程序不是当前主线；如后续要做，应作为独立客户端接入现有 API。

## 产品边界

- 当前不做多人协作。
- 当前不做公开社区。
- 当前不做支付。
- 当前不做完全自动替用户决策，只做结构化建议和复盘辅助。
