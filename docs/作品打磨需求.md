# 作品打磨需求（PRD）

> 目标：把决策助手打磨到**作品集/简历展示级**。风格基调：**克制、高级感优先，温暖但不幼稚**。
> 开发前先读 `docs/架构文档.md`、`docs/产品方向备忘.md`、`docs/进度账本.md`。**收工必须更新 `docs/进度账本.md`**。
> 两套 UI（Web `components/sheep.tsx`、Mobile `apps/mobile/src/components/Sheep.tsx`）是**两份 SVG 实现**，下方"角色规范"是它们共同的事实源，两边必须一致。

## 角色规范：小羊 4 种 mood（Web 与 Mobile 必须一致）

基础形象不变（羊毛、脸、眼=深色圆点+白高光、腮红、嘴=曲线、头顶蓝色决策分叉天线、角）。各 mood **只做克制微调**，禁止夸张卡通化：

| mood | 眼 | 嘴 | 天线(spread) | 其它 | 用在哪 |
|---|---|---|---|---|---|
| **idle**（默认） | 正常圆点 | 轻微闭口微笑 | 收拢(14) | 轻微上下浮动 | 首页问候、logo、详情页非关键处 |
| **thinking** | 瞳孔上移 1–2px（像在想） | 小而中性 | 张开(24) | 浮动略快、其中一颗天线点轻脉冲 | 生成/分析中页 |
| **happy** | 上弯弧线（眯眼笑 ⌒⌒） | 明显微笑 | 收拢(14) | 腮红略明显 | 空状态、登录成功 |
| **celebrate** | 眯眼笑 | 开口笑 | 收拢(14) | 一次性轻弹 + 2–3 个淡蓝小星点淡入淡出 | 报告生成完成、复盘完成 |

> 克制原则：弹跳幅度小、星点小且少、颜色用既有主蓝，不加新色。

## M1 · Web 小羊表情系统 + 动效

**1.1 `components/sheep.tsx` 扩展 `mood` prop**：`"idle" | "thinking" | "happy" | "celebrate"`，按上表渲染对应眼/嘴/腮红/天线。保持现有 `size` / `float` prop。

**1.2 动效参数（克制）**，统一写进 `globals.css`，全部受 `prefers-reduced-motion` 关闭：
- **浮动 bob**（已存在）：`translateY 0→-5px`，2.2s ease-in-out 循环。
- **眨眼 blink**：眼睛 `scaleY 1→0.1→1`，约 140ms，每 4–7s 随机一次（idle/happy 用）。
- **庆祝弹 celebrate**：一次性 `scale 1→1.06→1` + `translateY 0→-6→0`，约 450ms ease-out（mount 时触发一次）。
- **星点 sparkle**：2–3 个小圆点，`opacity 0→1→0` + 轻微上移，700ms，错峰，仅一次。
- **卡片淡入**：报告各卡 `opacity/translateY` 进入，120–160ms，错峰 ≤60ms。

**1.3 触发点接线（Web）**：
- 首页 hero：`idle`（bob + blink）
- 生成/分析中页 `/decisions/[id]/analyzing`：`thinking`
- 详情页首次渲染：`celebrate`（一次性），随后静置
- 空状态（首页最近决策空、历史空、画像空）：`happy`
- 复盘提交成功：`celebrate`（一次性，配 toast/提示）
- 顶栏 logo：`idle`，**不加动效**（避免分散）

**验收**：4 个 mood 视觉明显可辨但克制；触发点正确；`prefers-reduced-motion` 下所有循环/一次性动画关闭；`npm run lint && npm run build` 通过。

## M2 · Web 布局/响应式打磨

- **移动端导航**（<640px）：顶栏 4 项改为**底部固定 tab bar**（图标+文字：首页/历史/整理/我的），与 App tab 风格一致；≥640px 维持顶栏。点击区 ≥44px。
- **hero 小羊**：移动端也显示（现为 `sm:flex` 隐藏），手机用较小尺寸（约 64–72px）。
- **报告/详情页**：正文 `max-width` 控制可读性；结论卡更突出（已有左蓝条，校验层级）；各区块垂直节奏统一。
- **全局**：卡片圆角/阴影一致；间距用统一 spacing；标题字阶统一；移动端无横向溢出。

**验收**：360px / 768px / 1280px 三档无溢出、无错位；导航在手机可用；`build` 通过。

## M3 · 移动端小羊同步（Codex，仅 `apps/mobile/**`）

- `apps/mobile/src/components/Sheep.tsx` 按"角色规范"实现同样 4 个 mood（react-native-svg；动效用 `Animated`/`Reanimated`，blink 用 `scaleY`，celebrate 一次性弹）。
- 触发点：首页问候 `idle`；生成中页 `thinking`（已有大羊，补 mood）；空状态 `happy`；复盘完成 `celebrate`。报告区不放小羊（维持可信）。
- 受系统"减弱动态效果"开关影响则关闭循环动画。

**验收**：`apps/mobile` 下 `npm run typecheck` 通过；表情与 Web 一致；真机 Expo Go 能跑。

## M4 · 收口（作品级展示）

- **`README.md`**（仓库门面，简历直接挂）：一句话定位 + 截图（Web PC/移动 + App）+ 技术栈 + 架构简图 + 在线地址 + 本地运行说明 + "小羊设计/温暖外壳+理性内核"亮点。
- **一页产品/技术复盘**：可并入 README 末尾或单独 `docs/复盘.md`——讲清"做了什么、技术选型、踩坑（SDK/部署/账号体系）、产品判断（红海/分发）"。这部分是面试讲故事的料。
- **Web 首页下载入口**：APK 按钮 + 二维码（指向 `/api/download/android`）样式打磨；让访问者一眼看懂 Web 与 App 都可体验。

**验收**：陌生人点开仓库/网页，3 分钟内看懂"这是什么、谁做的、怎么试"。
