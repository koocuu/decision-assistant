# 决策助手运维手册

本文档记录环境、部署、密钥、迁移和出包相关操作。它是“怎么上线/怎么别把密钥弄丢”的事实源。

## 环境变量

本地真实环境变量放在仓库根目录 `.env`，不要提交。示例变量放在 `.env.example`。

```env
DATABASE_URL="postgresql://...neon.../...?sslmode=require"
DEEPSEEK_API_KEY="..."
DEEPSEEK_BASE_URL="https://api.deepseek.com"
DEEPSEEK_MODEL="deepseek-chat"
ANDROID_APK_URL="https://.../decision-assistant.apk"
```

生产环境变量在 Vercel Dashboard 设置。

## 密钥规则

- `DATABASE_URL` 只给服务端和 Prisma 使用。
- `DEEPSEEK_API_KEY` 只放服务端环境变量。
- Web 前端和 Expo App 都不能保存 DeepSeek key。
- Expo App 不能直连 Neon，必须走 Vercel `/api/*`。
- App 登录 token 应存 `SecureStore`，不要存普通 AsyncStorage。

## 数据库

- 数据库使用现有 Neon Postgres。
- Prisma schema 和 migration 在 `prisma/**`。
- 生产迁移必须由用户明确确认后执行。
- 不要自动对生产库跑新的 migration。
- 已部署的账号体系迁移：`20260624000000_add_accounts`。

## 部署

- Next Web 和 `/api/*` 部署在 Vercel。
- `main` 分支推送后由 Vercel 自动部署。
- 高风险改动要优先小步提交，确保可回滚。

## APK 下载

- Web 首页下载按钮和二维码指向 `/api/download/android`。
- `/api/download/android` 会跳转到 `ANDROID_APK_URL`。
- 生成真实 APK 后，把下载地址写入 Vercel 的 `ANDROID_APK_URL`。

## 常用检查

npm run lint
npm run build
npm run prisma:generate
```

移动端改动后在 `apps/mobile` 下运行：

```
